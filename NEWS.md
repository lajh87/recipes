# News

## 2026-05-04

This version expands recipe discovery and meal planning compared with the previous version.

- Added search filters for dietary requirements, duration, and UK seasonal produce.
- Added derived vegetarian and pescatarian recipe tags based on ingredients.
- Added a dedicated Manage Tags table for reviewing diet and seasonal tags across recipes.
- Added Manage Tags filters for book or collection, diet, season, and paginated recipe results.
- Added per-ingredient meat and fish classification overrides that update vegetarian and pescatarian tags.
- Added a local UK produce calendar for the “In season now” filter, using the current Europe/London month.
- Added recipe-page action to add the current recipe to the latest meal-plan week.
- Changed the meal-plan action button to a compact plus icon.
- Moved Manage Tags from the top navigation into Manage Metadata.
- Improved Plenty More EPUB extraction so serving notes and component headings are kept inside their parent recipes.
- Preserved checked shopping-list ingredients when the meal plan is autosaved or regenerated after adding recipes.
- Added tests for recipe filters, recipe tag management, EPUB extraction profiles, UK seasonality matching, adding recipes to the latest meal-plan week, and shopping-list checked state.
